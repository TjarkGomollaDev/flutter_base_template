# MARK_LXXXV (Flutter Clean Architecture Demo)

A Flutter app showcasing a **Clean Architecture** setup with four layers (**Presentation, Application, Domain, Infrastructure**) and **BLoC** state management.
The project is **not feature-complete** and is **not actively maintained** — it serves mainly as an architecture reference and a UI/login flow prototype.

## Highlights
- Clean Architecture: clear separation of concerns across 4 layers
- BLoC-based state management (events/states, async handling)
- Advanced login flow (near complete) + polished UI screens
- Modular, scalable code structure (easy to extend)
